Choosing a form saver

A Typio alternative with a short memory.

If you liked having a way back to an unfinished comment or form, Lifeboat fills that role in Chrome: save the words locally, then restore them when a page loses them.

Typio Reboot is an option too

Typio Form Recovery Reboot is a community-maintained version with a Manifest V3 release and a Chrome Web Store listing. Its maintainer's repository describes the current release and known editor limitations. Lifeboat is a separate product, not a Typio update or fork.

Why consider Lifeboat?

Lifeboat is built around a small rescue card and a readable list of saved drafts. When it recognises that a field has lost text, it offers Restore. The popup gives you another way to browse drafts, open earlier versions and copy text. Draft deletion is coming in v1.0.2.

The free defaults are deliberately brief: up to three versions of a field, kept for seven days, with saving beginning at 25 characters. You get useful recovery without building a permanent history of everything you type.

What it saves
Text you type into supported website fields, including many rich editors.
Where drafts live
In your Chrome profile on this device, encrypted with AES-GCM. No cloud sync or draft uploads.
How you recover
Restore into the original field, or use Copy and paste the text where you need it.
What you control
View and export drafts, browse earlier versions, and pause saving on a site. Coming in v1.0.2: delete a draft or a site's drafts with undo.
What it costs
Core rescue is free. A $3.99 one-time supporter pack adds four themes, configurable saving limits and private rescue counts.

Which workflow feels right?

If you want to keep Typio's right-click menu and Recovery Dialog, review Typio Reboot's documented workflow. If you want Lifeboat's rescue card, short free retention and Tin Toy interface, try the sample rescue simulation, then check the extension on the websites you actually use.

Editor compatibility is site-specific. Lifeboat supports ordinary inputs and many modern editors, including React-controlled fields and web components, but it cannot promise to restore into every custom editor. The Copy button is the fallback when the saved words exist but the original field no longer matches.

Before you switch

  1. Keep any old drafts you need. Copy or export them using your current tool. Lifeboat does not import a Typio database.
  2. Install Lifeboat before the next draft. It cannot recover text lost before it was installed and saving.
  3. Run a harmless check. Use the manual sample check in the current version. Test Lifeboat, coming in v1.0.2, adds a sample test inside the extension. Use harmless sample text to check any important custom editor.
  4. Know your save minimum. The free version starts at 25 characters. If a draft never reached that length, there may be no saved copy.

The privacy details matter

Lifeboat has no telemetry or draft cloud. Password fields and fields identified as payment or national-ID inputs are excluded using their field information. That does not identify a secret pasted into an ordinary text box; use site pause when you don't want text saved.

Pro activation and periodic licence validation send your licence key and organisation/activation identifiers to Polar, never your drafts. Read the privacy policy for the full scope.
